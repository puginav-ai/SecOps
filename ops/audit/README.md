# Разовая проверка офисных пакетов на АРМ

Повод: RCE в LibreOffice (CVE-2026-63277 — фикс в 26.2.5/26.8.0) и Apache OpenOffice
(CVE-2026-59265 — фикса нет до 4.1.17). См. бэклог в `docs/SDD.md`.
Вредоносная таблица Calc исполняет Java-код без предупреждений, если включена поддержка Java.

## Список машин

`make audit-list` — выгружает из DHCP-аренд роутера `machines.txt` (IP + имя ПК).
Только активные аренды; машины со статикой добавятся после сканов сегментов.

## Быстрый путь: запуск на самих АРМ (без прав администратора)

1. Скопировать `office_check.ps1` в общий каталог на файловом сервере,
   например `\\FS\SSX\inventory\` (папку создать один раз).
2. Попросить пользователей: правый клик по файлу → «Выполнить с помощью PowerShell»
   (или `powershell -ExecutionPolicy Bypass -File office_check.ps1`).
3. Рядом появятся отчёты `<ИМЯ-ПК>-<пользователь>.txt` — по ним видно версии офиса
   и наличие Java. По количеству файлов сразу виден охват.

Скрипт ничего не ставит, не требует прав администратора, читает только реестр
и пишет текстовый файл рядом с собой.

## Централизованный обход (если у ИТ есть общая учётка локального администратора)

Тот же сбор (`machines.txt` + чтение реестра по сети) — скрипт будет добавлен, когда
будет решён вопрос доступа. Пока в WORKGROUP без единой учётки он невозможен.
